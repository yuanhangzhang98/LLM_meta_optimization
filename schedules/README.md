# Experiment Schedules

This directory contains experiment schedule functions that determine what experiments to run on each design.

## Schedule File Format

Each schedule file `schedule_M.py` (where M is the schedule ID) must define:

```python
def schedule(design_id: int = 0) -> List[Dict[str, Any]]:
    """Execute experiments for a design.

    Args:
        design_id: ID of the design to evaluate

    Returns:
        List of experiment results, each dict containing:
        - Experiment parameters (N, batch, ratio, max_steps, etc.)
        - Experiment outcomes (median_step, unsolved_fraction, etc.)
    """
    ...
```

## Schedule Strategy

Schedules implement multi-fidelity testing strategies:

- **Adaptive schedules**: Start cheap, increase fidelity if promising
- **Fixed schedules**: Run predetermined set of experiments
- **Refinement schedules**: Add high-fidelity experiments to existing results
- **Quick schedules**: Fast evaluation for initial screening

## Available Schedules

- **schedule_0.py**: Baseline adaptive fidelity (N=10→320, adaptive stopping)

## Scheduler Agent

The scheduler agent analyzes designs and assigns appropriate schedule IDs:
- New designs → Initial exploration schedules
- Promising designs → Higher fidelity schedules
- Top performers → Refinement schedules

New schedule files are generated by the scheduler agent when needed.
