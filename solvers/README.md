# Solver Files Directory

This directory contains solver files generated by LLM agents during the automated research loop.

## Structure

- `solver_0.py` - Baseline solver (copied from template)
- `solver_N.py` - LLM-generated solver variants (N = experiment ID)

Each solver file is a complete, self-contained Python module that defines:
- `VARIABLES_SPEC` - State variable specifications
- `HYPER_SPACE` - Hyperparameter search space
- `_grad_single()` - Core dynamics function
- Helper functions and imports

## Usage

Solver files are dynamically imported by the executor during experiment runs:
```python
from solvers import solver_N
```

The metric evaluation system uses monkey patching to redirect `sat_solver` imports to the appropriate solver file.
